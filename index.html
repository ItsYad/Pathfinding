📖 How to Use

🎮 Getting Started:

  1. Choose Mode: Select between Draw Walls, Move Start, or Move End
  2. Draw Walls Mode: Click and drag on the grid to create obstacles
  3. Move Start/End: Click on any empty cell to place the start or end node
  4. Select Algorithm: Choose between BFS or Dijkstra from the dropdown
  5. Start Visualization: Click "Start Visualization" to see the algorithm in action

🎯 Button Functions:

  • ▶ Start Visualization: Run the selected algorithm
  • 🔄 Clear Path: Remove visited nodes and path (keeps walls)
  • 🧱 Clear Walls: Remove all walls from the grid
  • 🔃 Reset All: Reset everything to default state

💡 Tips:

  • Create mazes by drawing walls to test different scenarios
  • Move start and end nodes to different positions
  • Compare BFS and Dijkstra performance on the same maze
  • Watch the statistics to see algorithm efficiency

📚 About Algorithms

🔵 BFS (Breadth-First Search)

Description: BFS adalah algoritma traversal graph yang mengeksplorasi semua node pada level saat ini sebelum pindah ke level berikutnya.

How it Works:

  1. Mulai dari start node dan masukkan ke queue
  2. Ambil node dari queue dan kunjungi semua tetangganya
  3. Tandai node sebagai visited dan tambahkan tetangga yang belum dikunjungi ke queue
  4. Ulangi sampai menemukan end node atau queue kosong

Complexity:

  • Time Complexity: O(V + E) - V adalah jumlah vertices, E adalah jumlah edges
  • Space Complexity: O(V) - untuk menyimpan queue dan visited nodes

Best Use Case:

  • Unweighted graphs (semua edge memiliki bobot sama)
  • Mencari jalur terpendek dalam unweighted graph
  • Level-order traversal

🟢 Dijkstra's Algorithm

Description: Dijkstra adalah algoritma greedy untuk mencari jalur terpendek dari satu node ke semua node lainnya dalam weighted graph dengan bobot non-negatif.

How it Works:

  1. Set jarak start node = 0, node lain = infinity
  2. Pilih node dengan jarak terkecil yang belum dikunjungi
  3. Update jarak ke tetangga jika ditemukan jalur yang lebih pendek
  4. Tandai node sebagai visited
  5. Ulangi sampai semua node dikunjungi atau end node tercapai

Complexity:

  • Time Complexity: O((V + E) log V) - dengan priority queue
  • Space Complexity: O(V) - untuk menyimpan distance array

Best Use Case:

  • Weighted graphs dengan bobot positif
  • Mencari shortest path dalam road networks
  • GPS navigation systems
